tufazip-rs

Compression & Decompression Pipeline

Both compression and decompression run identical online training steps at every coding block so decoder logits match encoder logits without storing per-token side information beyond the binary .voc table and optional prior.

  1. 1. NNCP Dictionary Preprocessing (tufazip-preprocess)

    Pure-Rust port of Fabrice Bellard’s preprocess.c encoding Unicode whitespace/capitalization escapes and inducing up to 65,536 bigram dictionary tokens (.voc + big-endian u16 .pp streams).

  2. 2. Quantized Prior Loading (tufazip-prior)

    Parses and verifies QPI1, QPR1, LRA1, and QLA1 weight archives at 1/2/4/8/16-bit widths, expanding 2-layer loop-untying or depth-growth priors into 12-layer targets without wasting PRNG draws.

  3. 3. Neural Context Modeling & Online Adaptation (tufazip-codec)

    Runs a Candle-backed Transformer (Peri/Post RMSNorm, RoPE or learned-relative attention, QK-Norm, SwiGLU) updated online with deterministic Adam, gradient norm clipping, prefix replay, and atomic safetensors + JSON checkpoints.

  4. 4. 32-bit Arithmetic Coding (tufazip-arith)

    Converts logits to deterministic integer cumulative frequencies (FREQ_TOTAL = 10,000,000, round-half-to-even) and writes or decodes resumable big-endian bitstreams with byte-exact checkpoint restoration.

Cross-Hardware Determinism Note

tufazip-rs provides bit-exact self-consistent compression, decompression, and checkpoint resume using fixed ChaCha8Rng PRNG streams, safetensors + JSON state snapshots, and integer frequency tables. Upstream’s precomputed enwik9-v2.bin (100,958,324 bytes) depends on a pinned 2× NVIDIA B200 CUDA 13.0 / cuDNN 9.20 BF16 FlashAttention + NCCL DDP reduction trajectory; pass --skip-verify to v2-decode when testing on other hardware.
